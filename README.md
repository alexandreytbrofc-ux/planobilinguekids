ARQUITETURA PRINCIPAL DA PÁGINA

==================================================

Esta página possui uma característica visual muito importante:

Mesmo em telas grandes, o conteúdo continua em uma COLUNA CENTRAL ESTREITA.

A estrutura principal deve funcionar aproximadamente assim:

body:

- fundo branco

main/page-wrapper:

- width: 100%

- max-width: aproximadamente 576px

- margin: 0 auto

- overflow-x: hidden

- fundo controlado individualmente pelas seções

NÃO expanda a landing page para 1100px, 1200px ou 1440px.

Em desktop devem existir grandes margens brancas nas laterais e a landing page centralizada.

Em celulares:

- preservar exatamente a proporção e hierarquia da página original

- padding lateral pequeno

- sem overflow horizontal acidental

Esse comportamento é FUNDAMENTAL.
